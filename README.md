# Blue Wave Pool Service (sample site)

A sample website I designed for Blue Wave Pool Service, a pool service company in Tampa, FL. I put together sites like this to show local businesses what a modern, mobile-friendly web presence could look like for them before they commit to anything.

**Live preview:** https://preview-blue-wave-pool-service.vercel.app

## Design

A photo-led design: a full-screen pool hero, a stock-photo mosaic gallery (every image is labelled as a stock photo), Montserrat with Lora italics, and an ocean-blue and aqua palette with a wave divider. The goal was calm and clean, like clear water.

## Stack

- Plain HTML and CSS in a single `index.html`, with no framework and no build step
- Responsive, mobile-first layout
- Fonts and images: Montserrat and Lora, plus photos from Unsplash (credited on the page)
- Hosted on Vercel

## Running it locally

Open `index.html` in a browser, or serve the folder with something like `npx serve .`

## Notes

- This is a sample site, not the business's official website, and it isn't affiliated with or published by Blue Wave Pool Service.
- The contact form is for demo purposes only and doesn't send anything.
- Search engines are blocked for now (`robots.txt` and a `noindex` header in `vercel.json`) until the business decides whether it wants the site live.
